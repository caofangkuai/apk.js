主题

apk.js在浏览器里跑 Android APK

解析 DEX、执行字节码、把界面画到 Canvas 上，全程纯 JavaScript。

快速开始
简介

纯前端

解压、解析、执行和渲染都在浏览器内完成，不需要后端、设备或模拟器。

DEX 解释器

执行 Dalvik 字节码，支持异常处理、switch、数组、字段和方法调用。

Canvas 版 Framework

用 Canvas 实现 Android Framework 子集，渲染 Activity、View、布局、控件、可绘制资源和主题。

资源保真

直接读取二进制 AndroidManifest.xml 和 resources.arsc，主题和字符串都来自 APK 本身。

接口精简

createSimulator 负责设备尺寸、文件加载和日志回调，放进任意静态页面即可。

出图调试

tools/render-apk.mjs 用 node-canvas 跑真实 APK 并输出 PNG，方便做视觉对照。
